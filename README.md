## Sobre

Sou **Josué Silva de Morais**, **professor** na **UFU (FEELT)**, atuando no curso de **Engenharia de Controle e Automação**.  
Meu trabalho conecta **fundamentos de controle e automação** com **software, dados e inteligência artificial** para criar soluções **robustas**, **reprodutíveis** e com **impacto real**.
